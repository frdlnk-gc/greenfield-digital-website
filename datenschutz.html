Verwendung von Meta Pixel (ehemals Facebook Pixel)

Unsere Website verwendet den Meta Pixel, einen Analysedienst der Meta Platforms Inc. (ehemals Facebook). Der Meta Pixel ermöglicht es uns, das Verhalten von Besuchern nachzuverfolgen, nachdem sie durch einen Klick auf eine Meta-Anzeige auf unsere Website weitergeleitet wurden. Dies dient dazu, die Effektivität von Meta-Anzeigen für statistische und Marktforschungszwecke auszuwerten und zukünftige Werbemaßnahmen zu optimieren.

Die erhobenen Daten sind für uns anonym, d. h., wir sehen keine personenbezogenen Daten einzelner Nutzer. Meta speichert und verarbeitet jedoch die Daten, sodass eine Verbindung zum jeweiligen Nutzerprofil möglich ist und Meta die Daten für eigene Werbezwecke verwenden kann, gemäß der Meta-Datenrichtlinie. Dies ermöglicht Meta, das Schalten von Anzeigen auf Meta-Plattformen sowie außerhalb der Meta-Plattformen zu ermöglichen. Diese Nutzung der Daten kann von uns nicht beeinflusst werden.

Die Datenverarbeitung durch Meta erfolgt im Rahmen der Datenschutzrichtlinie von Meta: facebook.com/about/privacy. Sie können der Erfassung durch den Meta Pixel und der Verwendung Ihrer Daten zur Schaltung von Meta-Anzeigen widersprechen. Dazu können Sie die Opt-out-Funktion in den Einstellungen Ihres Meta-Nutzerkontos verwenden: facebook.com/settings?tab=ads.

Sie können die Speicherung der Cookies durch eine entsprechende Einstellung Ihrer Browser-Software verhindern; wir weisen Sie jedoch darauf hin, dass Sie in diesem Fall gegebenenfalls nicht sämtliche Funktionen dieser Website vollumfänglich nutzen können. Sie können darüber hinaus die Erfassung der durch das Cookie erzeugten und auf Ihre Nutzung der Webseite bezogenen Daten (inkl. Ihrer IP-Adresse) an Google sowie die Verarbeitung dieser Daten durch Google verhindern, indem Sie das unter dem folgenden Link verfügbare Browser-Plugin herunterladen und installieren: Browser Add-On zur Deaktivierung von Google Analytics.
